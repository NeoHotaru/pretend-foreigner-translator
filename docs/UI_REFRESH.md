# 桌面界面统一改版

视觉方向：轻巧的对话工作台。译文是阅读主角；蓝色代表自己的表达，青绿色代表对方消息。

- 底色 `#F6F7F9`，阅读面 `#FFFFFF`，正文 `#202A38`，次要文字 `#606E81`，边线 `#E3E8EF`。
- 我方操作 `#315FCC`；对方操作 `#177C70`。不增加装饰渐变或无意义的徽章。
- 同一套中文字体：优先本机 MiSans，再用 Noto Sans SC，最后回退 Microsoft YaHei UI。
  正文 12 pt，重要译文 15 pt，标题 14/24 pt，元信息 9 pt。
- 输入与阅读区使用留白、轻边界和细滚动条。未溢出的内容不显示滚动条。
- 普通操作、主操作、禁用、悬停、按下、焦点各有明确状态。保留原生键盘与无障碍行为。
- 设置分为翻译服务、输入与悬浮、语音、软件更新，不再放进一张长表单。
- 高频选区按钮与快捷键即时响应；悬浮岛保留已有可中断展开动效。

布局：主窗口仍是左右两条消息线，分别为「我想说」与「对方说」。设置使用分类页；
对方译文框优先显示译文，原文和所属会话收进次要层级。浮层共用正文排版与操作控件。

复核：保留品牌图标与两侧消息线，减少默认控件年代感；复杂度用于清晰状态与可读性，
不用于额外装饰。通过真实截图、短/长译文、鼠标选区、键盘操作与设置保存验证。

## 最小化恢复性能修复

复现发现，原来的 28 px 控件底图和 40 px 分栏底图会被 ttk 重复平铺。
大面积圆角面板的中心仅 8 px 宽，Windows 恢复窗口时要执行大量透明图片绘制，
出现逐块变黑、数秒后才恢复完整画面的现象。

底图中心扩大至 256 / 512 px，控件最小尺寸仍明确保持 28 / 40 px。
分栏位置只在主窗口第一次显示时恢复，避免每次恢复对 90 个子控件重复执行布局。
主线程心跳最大间隔从原来的约 1.4 秒降到约 0.06–0.14 秒，三轮恢复后 0.5 秒采样均无持续黑块。
Windows 恢复最初约 0.2 秒的个别采样仍可出现短暂重绘；未承诺完全无中间帧。

`check_window_restore.py` 检查界面响应、分栏和草稿保留；
`check_input_exe.py --restore-only` 已验证原试用目录中的 EXE 连续三次恢复。
构建中因正在运行的旧程序占用文件而先输出暂存目录；用户关闭程序后，已将完整构建复制回原试用目录。
原目录的 EXE 已再次通过参考消息气泡与原位选区翻译回归，真实配置和会话文件未被测试修改。
暂存目录在核对 EXE 哈希一致后已清理。
